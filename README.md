# Netflix Clone
 
A copy of the Netflix landing page made with just HTML and CSS. I followed a tutorial and its source code changing a lot.
 
This is only a practice project. It's not the real Netflix and it doesn't do anything when you click Sign In.
 
## What's on the page
 
- Navbar with language and sign in buttons
- Hero section with the email box
- 4 feature sections (TV, downloads, devices, kids profiles)
- Trending Now row with movie posters
- FAQ boxes
- Footer with links
## What I changed from the tutorial
 
- New colours and fonts
- Round buttons with a hover effect
- Gradient dividers instead of grey bars
- Added the Trending Now row (it scrolls sideways on small screens)
- Fixed a few typos and the email input type
- Merged the repeated media queries into one
## Run it
 
No setup needed. Download the folder and open `index.html` in your browser.
